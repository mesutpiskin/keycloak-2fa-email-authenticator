# Contributing

Contributions are welcome. Here are the ways you can help.

:::info Project guidelines

Before contributing, please read the guidelines in the repository:

- [Contributing guide](https://github.com/mesutpiskin/keycloak-2fa-email-authenticator/blob/main/CONTRIBUTING.md) — development setup, workflow, commit conventions, and pull request checklist
- [Code of Conduct](https://github.com/mesutpiskin/keycloak-2fa-email-authenticator/blob/main/CODE_OF_CONDUCT.md)
- [Security policy](https://github.com/mesutpiskin/keycloak-2fa-email-authenticator/blob/main/SECURITY.md) — report vulnerabilities privately, never as a public issue
- [Accessibility](https://github.com/mesutpiskin/keycloak-2fa-email-authenticator/blob/main/ACCESSIBILITY.md) — goals, known limitations, and how to report a barrier
- [Keycloak compatibility](https://github.com/mesutpiskin/keycloak-2fa-email-authenticator/blob/main/COMPATIBILITY.md) — which Keycloak versions each release supports

:::

## Ways to Contribute

| Type                 | Description                           |
| -------------------- | ------------------------------------- |
| **Translations**     | Add a new language — see guide below  |
| **Bug Reports**      | Use the Bug Report issue template     |
| **Feature Requests** | Use the Feature Request issue template |
| **Accessibility**    | Use the Accessibility Issue template  |
| **Pull Requests**    | Fix bugs or implement new features    |

## Contribution Guidelines

```bash
# 1. Fork and clone
git clone https://github.com/<your-fork>/keycloak-2fa-email-authenticator.git

# 2. Create a branch
git checkout -b feat/my-improvement

# 3. Build and test
mvn -B package

# 4. Commit using Conventional Commits
git commit -m 'feat: add my improvement'

# 5. Push and open a PR
git push origin feat/my-improvement
```

**Code standards:**

- Follow existing code style and conventions
- Add comments only for non-obvious logic
- Update docs when changing behavior
- Test your changes before submitting

## Adding a Translation

import Tabs from "@theme/Tabs";
import TabItem from "@theme/TabItem";

<Tabs>
  <TabItem value="steps" label="Steps" default>

1. Copy the English file:

   ```bash
   cd src/main/resources/theme-resources/messages/
   cp messages_en.properties messages_<lang>.properties
   ```

2. Translate all values — **do not change the keys**:

   ```properties
   # German example
   resendCode=Code erneut senden
   emailOtpForm=Bitte geben Sie den {0}-stelligen Code ein, der an Ihre E-Mail-Adresse gesendet wurde.
   ```

3. Build and verify:

   ```bash
   mvn clean package
   ```

   Deploy to Keycloak, switch browser language, confirm all messages display correctly.

4. Create a PR with branch name `i18n/<lang>-messages`.

  </TabItem>
  <TabItem value="keys" label="Translation Keys">

See the [Localization page](./localization#translation-keys-reference) for the full reference of all keys with descriptions and placeholders.

  </TabItem>
</Tabs>
